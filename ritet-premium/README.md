# RITET — премиум-версия сайта (лендинг)

Современная одностраничная премиум-версия сайта **ritet.net** (ООО «РИТЕТ» —
поставщик промышленного электрооборудования EMAS, RAAD, Rade Končar).

## Что это
Самодостаточный файл `index.html` — без сборки, без зависимостей. Можно открыть
локально двойным кликом или залить на любой хостинг (в т.ч. на Bitrix как отдельную
страницу). Единственный внешний ресурс — шрифт Manrope с Google Fonts (при недоступности
подхватывается системный шрифт).

## Структура
- `index.html` — вся страница (HTML + CSS + JS в одном файле)
- `img/din-reyki-sale-60.png` — промо-баннер акции −60% на DIN-рейки

## Разделы
Шапка с навигацией и телефоном · Первый экран (hero) с интерактивной подсветкой ·
Промо-баннер −60% · Каталог (реле времени, реле, концевые выключатели, кабельные каналы,
DIN-рейки, весь ассортимент) · Преимущества · Бренды · Контакты с формой заявки · Футер.

## Особенности
- **Адаптив**: desktop / планшет / мобильный, проверено на 360–1440px, без горизонтального скролла.
- **Производительность**: нет тяжёлых библиотек; анимации на CSS + IntersectionObserver.
- **Доступность**: skip-link, `:focus-visible`, aria-атрибуты, клавиатурная навигация, `prefers-reduced-motion`.
- **Прогрессивное улучшение**: контент виден даже с отключённым JavaScript.
- **SEO**: title, description, Open Graph, favicon.

## Что заменить на реальное (когда будут исходники сайта)
- **Логотип**: сейчас текстовый «RITET» с красной плашкой — вставьте фирменный логотип.
- **Точные фирменные цвета** и **полные тексты** блоков — при наличии доступа к сайту.
- **Email** `info@ritet.net` — подставлен как типовой, уточните реальный.
- **Форма заявки**: сейчас демо (без бэкенда). На боевом сайте подключить отправку
  (Bitrix «Веб-форма», письмо на почту или CRM).

## Предпросмотр
Откройте `index.html` в браузере. Для быстрой проверки вёрстки использовались скриншоты
из headless-Chromium (в репозиторий не коммитятся).
