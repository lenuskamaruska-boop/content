# Контент-завод · ФУЛЛ

8 агентов, которые придумывают, пишут и оформляют контент.
Ты остаёшься редактором: завод присылает черновики, публикуешь всегда ты.

> Ещё не настроил? Открой эту папку в Claude Code и напиши «настрой меня» — он проведёт.
> Подробности — в **НАЧНИ-ОТСЮДА.md**.

---

## Кто здесь работает

| Агент | Что делает |
|---|---|
| **Ревизор** | Стоит над всеми. После каждого прогона проверяет результат: сломалось — перезапустит, вышел брак — перегенерирует, не смог — позовёт тебя |
| **Аналитик** | Смотрит статистику, тренды и канал, предлагает 3 темы с обоснованием |
| **Контент-менеджер** | Раскладывает тему по площадкам: что в Telegram, что в Instagram, каким форматом |
| **Копирайтер** | Пишет пост твоим голосом |
| **Карусель-мейкер** | Собирает карусель и рисует готовые слайды PNG |
| **Рилс-мейкер** | Пишет сценарий рилса |
| **Гайд-мейкер** | Делает лид-магнит: гайд в PDF по теме |
| **Постер** | Ставит готовое в очередь публикации (только по твоей команде) |

## Каждый день: просто говори с ботом

Основной режим — переписка в том чате, куда приходят черновики.
Запусти завод один раз, и он слушает:

```
npm start
```

Дальше пиши боту обычными словами:

| Скажи | Что будет |
|---|---|
| «сделай пост про Х» | Цепочка агентов напишет пост |
| «сделай карусель про Х» | Карусель + готовые слайды картинками |
| «сделай рилс про Х» | Сценарий рилса |
| «сделай гайд про Х» | Гайд в PDF |
| «покажи тренды» | Аналитик соберёт свежие темы |
| «изучи канал» | Разберёт твой Telegram-канал |
| «вопросы аудитории» | Соберёт, о чём спрашивают подписчики |
| «план на неделю» | Соберёт недельный план |
| «запиши идею: …» | Положит в копилку идей |
| «покажи идеи» | Достанет копилку |
| «опубликуй» | Поставит в очередь публикации |

**Голосом тоже можно** — надиктуй задание, завод расшифрует (нужен ключ Groq).

Пока агент показывает черновик, отвечай ему:

- **ок** — принять и передать дальше
- **переделай** — заново с нуля
- **перерисуй** — тот же текст, новый дизайн (для каруселей)
- **стоп** — отменить
- или просто напиши, что поправить: «сделай короче», «убери про цены»

## Команды в терминале

```
npm start              запустить завод (слушает бота + расписание)
npm run copywriter     только пост
npm run carousel       только карусель
npm run reels          только рилс
npm run analyst        только аналитика
npm run run-all        вся цепочка подряд
npm run review-test    самопроверка, должно быть 4/4
node setup.js          мастер настройки вручную (можно перезапускать)
node setup.js --verify проверить, что все доступы живые
```

> Проще всего не запоминать команды, а сказать Claude Code словами:
> «сделай пост про Х», «проверь настройку», «почему не работает».
> Он знает этот проект — инструкция для него лежит в `CLAUDE.md`.

## Автопрогон по утрам

Когда завод стоит на сервере (см. раздел выше), каждый будний день в 7:30 он сам собирает
аналитику и пишет пост, присылает тебе. Публикацию не трогает — это всегда твоё решение.

⚠️ **Пока завод на ноутбуке, автопрогон не работает** — он срабатывает, только пока процесс
запущен, а ноутбук закрывается и засыпает. «Само по утрам» появляется после установки на сервер.

Поменять время или выключить — в файле `.env`:

```
DAILY_CRON_EXPR=30 7 * * *     когда запускать (по-умолчанию 7:30 будни)
DAILY_CRON=off                 выключить автопрогон совсем
TZ=Europe/Moscow               твой часовой пояс
```

## Как настроить завод под себя

**Голос и ниша — файл `persona.md`.**
Это главное. Изменил persona — изменились все агенты сразу.

**Инструкции агентов — папка `prompts/`.**
Обычные текстовые файлы. Не нравится, как пишет копирайтер — открой
`prompts/копирайтер.md` и перепиши под себя. Код трогать не надо.

Сейчас туда вынесены шесть: `аналитик`, `контент-менеджер`, `копирайтер`,
`карусель-мейкер`, `рилс-мейкер`, `ревизор`. Гайд-мейкер и постер работают
по встроенным правилам — их поведение задаётся форматом, а не голосом.

Внутри промптов есть подстановки, их не удаляй:

- `{{ГОЛОС}}` — сюда подставится твой `persona.md`
- `{{ЗАПРЕТЫ}}` — общий список штампов, которых надо избегать
- `{{ФАКТЫ}}` — правило «не выдумывать факты о тебе»

> Завод не привязан к контенту про блог. Меняешь persona и промпты — получаешь
> завод под свою задачу: карточки товаров, отчёты, обучающие материалы.
> Движок один и тот же.

## Чтобы работало само (сервер) — обязательно для автопилота

Пока завод запущен на ноутбуке — он работает только пока ноутбук включён и не спит.
**Утренний авто-прогон в 7:30 и автопостинг живут только на сервере 24/7** — без сервера
завод остаётся ручным помощником: пишешь боту, получаешь пост.

Это и есть Шаг 7 настройки — Claude Code проведёт по нему за руку, ему достаточно сказать
«хочу поставить на сервер». Коротко, что происходит (сервис — Railway, ~5$/мес):

1. Ставится Railway CLI, вход через браузер (`railway login`)
2. Создаётся проект (`railway init`)
3. Доступы из `.env` переносятся в переменные проекта + `TZ=Europe/Moscow`
4. `railway up` — папка заливается, завод поднимается и держится всегда

⚠️ **Файл `.env` на сервер не заливается** — только переменные. В комплекте есть `.gitignore`.
Оплата Railway из России — та же стена, что с Claude, варианты в `ДОСТУПЫ.md`.
(Кто дружит с GitHub — можно и через приватный репозиторий, но `railway up` из папки проще.)

## Если что-то не так

**Завод не стартует, пишет про persona.md** — заполни `persona.md`.

**«credit balance is too low»** — кончились деньги на аккаунте Claude.

**Бот молчит** — прогони `node setup.js`, он проверит связь.

**Карусель без фото** — не настроен Google Диск, см. `ДОСТУПЫ.md`.

**Тексты не похожи на тебя** — дело почти всегда в `persona.md`:
добавь больше живых примеров своей речи, они решают.

Остальное — в `ДОСТУПЫ.md`, раздел «Если застрял».
