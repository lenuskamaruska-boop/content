# Начни отсюда

Ты держишь контент-завод — 8 агентов, которые придумывают, пишут и оформляют контент.

**Настраивать вручную ничего не надо.** Открой эту папку в Claude Code, и он проведёт
тебя по всем шагам сам: спросит нужное, всё запишет, проверит и запустит первый пост.

---

## Как начать — три действия

### 1. Распакуй папку

Не запускай завод из архива. Распакуй в удобное место — например, в «Документы».
Запомни, куда положил.

### 2. Открой эту папку в Claude Code

Открой Claude Code и укажи ему **эту самую папку** — ту, где лежит этот файл.

> Claude Code ставили в уроке 3. Если у тебя его ещё нет — вернись к тому уроку,
> без него дальше не пойдёт.

### 3. Напиши ему одну фразу

```
Привет! Я купил завод, настрой меня
```

Всё. Дальше он ведёт.

---

## Что будет дальше

Claude спросит по одному, без свалки:

1. **Ключ Claude** — мозг завода
2. **Бот в Telegram** — будет присылать тебе черновики
3. **Группу для черновиков** — куда бот пишет
4. **Расскажет о тебе** — возьмёт короткое интервью и сам заполнит твой голос
5. **Остальное — по желанию:** голосовые команды, фото на обложки, автопостинг

После этого сам поставит всё нужное и сделает первый пост — он придёт тебе в Telegram.

Займёт около часа. Большая часть — не сложная, а нудная: завести аккаунты и получить ключи.

---

## Одно предупреждение, чтобы не потерять день

Самая частая засада — **деньги на аккаунте Claude**.

Создать аккаунт мало. Нужно **пополнить счёт** на console.anthropic.com → Plans & Billing.
На нулевом балансе ключ выглядит рабочим, но ничего не делает.

И второе: **деньги и ключ должны быть на одной почте.** Если у тебя несколько аккаунтов —
бери ключ там, где видишь баланс. На этом спотыкаются чаще всего.

Оплата из России — отдельная история, разобрана в `ДОСТУПЫ.md`.

## Если хочешь без Claude Code

Можно и по-старому, руками в терминале:

```
node setup.js
```

Тот же путь, только вопросы задаёт скрипт. Проверить настройку в любой момент:

```
node setup.js --verify
```
