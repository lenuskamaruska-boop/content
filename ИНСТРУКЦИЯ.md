## Публикация бесплатно (GitHub Pages)

### Шаг 1. Включить публикацию (один раз)
1. Откройте: **https://github.com/lenuskamaruska-boop/content/settings/pages**
2. **Source** → выберите **Deploy from a branch**
3. **Branch** → `claude/avenue-fashion-boutique-site-0k84d5`, папка `/ (root)` → **Save**
4. Подождите 1–2 минуты и обновите страницу.

### Шаг 2. Готово!
Вверху страницы появится ссылка вида:

### 👉 https://lenuskamaruska-boop.github.io/content/

Это рабочий адрес сайта — бесплатно и с HTTPS 🔒. Можно отправить сестре или поставить в шапку Instagram.

## 💎 Если захотите красивый домен потом (avenue-boutique.com)
Сайт легко переехать на свой домен в любой момент — **переделывать ничего не нужно**:
1. Купить домен (напр. на namecheap.com, ~$10–12/год).
2. Сказать мне имя домена — я добавлю файл `CNAME` обратно.
3. Прописать DNS у регистратора (4 A-записи GitHub + CNAME для www).
4. В Settings → Pages вписать домен в «Custom domain».

Подробности дам, когда будете готовы.

## 📝 Как менять сайт потом
- **Цены / названия / размеры** — файл `assets/js/main.js`, блок `PRODUCTS`
- **Фото товаров** — заменить файлы `assets/img/product-1.jpg … product-9.jpg`
- **Тексты на 3 языках** — `assets/js/main.js`, блок `I18N`
- **Контакты** — `assets/js/main.js`, блок `CONFIG`
